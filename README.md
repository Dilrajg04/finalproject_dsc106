# San Diego Temperature vs The World
DSC 106 Final Project · Kyle Shiroma, Yue Hu, Dilraj Grewal, Roberto Echeverria Sosa

Explorable explanation comparing projected warming in San Diego with 23 major world cities, using 5 CMIP6 climate models (D3 v7 only).

## 1. Get the data (Google Colab, ~10-25 min)
1. Go to colab.research.google.com → File → Upload notebook → `pipeline/fetch_cmip6.ipynb`
2. Runtime → Run all
3. The last cell downloads `cities.json`. Put it in this repo's `data/` folder.

## 2. View locally
```
python3 -m http.server 8000
```
Open http://localhost:8000

## 3. Deploy
Public repo → Settings → Pages → Branch `main`, folder `/ (root)` → Save.

## Files
| Path | What |
|---|---|
| `index.html`, `style.css`, `main.js` | The site (top level, as required) |
| `data/cities.json` | Generated by the pipeline (yearly warming per city, model, scenario) |
| `data/countries-110m.json` | World map outlines (world-atlas, Natural Earth) |
| `pipeline/fetch_cmip6.py` / `.ipynb` | Downloads CMIP6 `tas` from Google Cloud and builds `cities.json` |
